Google Firebase Cloud Messaging (FCM) Service Account Key Setup
================================================================

To allow devices to wake each other up with high-priority VoIP call pushes even when the app is completely closed or killed:

Option 1 (Recommended for Local Build):
1. Go to Firebase Console -> Project Settings -> Service Accounts.
2. Click "Generate new private key".
3. Rename the downloaded file to "service-account.json".
4. Place it in this directory: app/src/main/assets/service-account.json

Option 2 (Remote Firestore Config - No APK re-compilation needed):
1. In Firebase Console -> Firestore Database:
2. Create a collection named "system_config", document ID "fcm".
3. Add fields:
   - projectId: "veil-2b956"
   - clientEmail: "<your-service-account-client-email>"
   - privateKey: "-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"
